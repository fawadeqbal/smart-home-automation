A scene switches several devices at once. For example, **Good night** can turn every light off and leave the bedroom fan on.

## Create a scene (web app)

1. Open **Automations** and, under **Scenes**, press **New scene**.
2. Give it a **Name**, such as "Good night", "Leaving home" or "Movie time". Each name can be used only once in a home.
3. Under **Set each device you want in the scene**, choose on or off for every device you want included. Leave out the others.
4. Press **Save scene**.

You can only add devices you're allowed to switch. Scenes are created in the web app. The phone app's **Routines** tab runs them but doesn't create them.

## Run a scene

- **Web:** tap the scene's chip on **Home**, or press **Run** next to it in **Automations**.
- **Phone app:** **Routines** → **Scenes**, then tap the scene. You get **Undo** for a few seconds.
- **Voice:** say its name, for example "good night" or "run good night".
- **On a schedule:** create a timer or daily schedule and choose **Run a scene** (see "Set a timer or a daily schedule").

## Who can run and delete it

- Everyone in the home sees the scenes. You can run one only if you're allowed to switch **every** device in it. If you can't, its **Run** button is greyed out with the message "You may not control every device in this scene".
- Only the person who created a scene, or an owner or admin, can delete it (the bin icon in **Automations**).

## If a scene only partly worked

The app tells you what was done and what failed, for example "Done: Bulb off. Failed: Fan: … did not respond." The usual cause is a board that is offline or not responding. See "A board is offline".

If a device in a scene was later removed, the scene lists it as "Removed device". Delete the scene and create it again.
